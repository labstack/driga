:::caution[Experimental]
Windows support is feature-complete pending verification on real hardware.
Real agent sessions, logon and restart, notifications, orphan shutdown and
Recycle Bin restore still need that verification.
:::

Windows 10 1809+ and Windows 11 have native snapshots, foreground collection,
the read commands, the terminal UI, the desktop app, MCP, OTLP intake and
fleet. Install with [Scoop](/start/install).

## Collector

`Driga.exe`, the app, runs the CLI next to it, `bin\driga.exe`, as its
collector without a console window. It sits in the notification area, shows
how many sessions need you in its tooltip and menu, and starts at logon. Scoop
adds a Start menu shortcut for Driga and puts `bin\driga.exe` on `PATH` as
`driga`; `driga app` opens the app from a terminal.

On a machine without the app, `driga service install` registers a per-user
Task Scheduler task, **Driga collector**, that runs at logon with least
privilege. It needs no password, elevation or PowerShell. `start`, `stop`,
`restart`, `status`, `logs [-f]` and `uninstall` work as on other platforms. Logs are at
`%LOCALAPPDATA%\driga\logs\collector.log`, bounded to 10 MiB plus one rotated
file.

The task records the home, temporary-directory and Driga path overrides at
installation; reinstall after changing them. Installation refuses an existing
task, so uninstall before changing the binary path.

## Hooks

Hook installation previews the diff as on Unix. Claude and Copilot hooks use
the executable-plus-arguments form with an absolute path, which avoids shell
quoting entirely. The Codex hook uses
`cmd.exe /d /c call "<absolute driga.exe>" hook codex PermissionRequest`, so
the install path must not contain shell metacharacters such as `%`, `!`, `&`,
parentheses, `$` or backticks. Spaces, apostrophes and Unicode are fine.
`CLAUDE_CONFIG_DIR`, `CODEX_HOME` and `COPILOT_HOME` are respected.

## Alerts and jumps

Alerts are plain WinRT toasts without click actions; use `driga inbox` and
`driga inbox jump <item>` to navigate. Focus Assist and notification policy can
suppress them, and `driga doctor` reports availability.

Jumps open Windows Terminal (`wt.exe -d <cwd>`) or, failing that, a new Command
Prompt in the session's directory. Stored resume commands are shown for
copying, never executed.

## Orphans and cleanup

`driga orphans kill` uses the same candidates and confirmations as Unix. Every
process start time in a tree is pinned and checked again before acting. The
graceful step posts `WM_CLOSE` to the process's own windows; after the grace
period, `--force` terminates through an identity-checked handle. Headless
processes may need `--force`.

Verified linked worktrees are moved to the Recycle Bin, then Git worktree
metadata is pruned. Claude scratch cleanup is refused because its Windows
layout is not yet established, and `driga doctor` explains this.
