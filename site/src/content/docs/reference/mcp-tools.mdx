`driga mcp` serves read tools and panel tools over stdio. Every read tool
answers with the same schema-2 view envelope as the CLI's `--json` output, and reading never
acknowledges inbox items. Without the Driga service running the tools answer from a
labelled one-shot snapshot with no history. Registration is covered in
[Connect an agent over MCP](/guides/mcp).

Every read tool shares this contract:

> Use this to inspect collected state without changing it; safe to retry. Optional scope fields select machine (default all) and project where supported; for example \{"limit":100\}. Returns a schema-2 envelope with data, UTC observed_at, source freshness and coverage gaps; mode: "snapshot" means no history. limit bounds total array entries, including nested collections (default 100, maximum 500). truncated=true means entries were omitted: narrow the scope or increase limit. Reading never acknowledges inbox items.
