Driga reads `config.toml` and the process environment. Precedence is explicit
flags, then environment, then the TOML file, then the defaults below. Empty
environment values count as unset, and dotenv files are never loaded. An
unknown `DRIGA_*` name is an error. Restart the collector after changing its
configuration; the CLI and hooks reload on every invocation.

Find and edit the file with `driga config path`, `driga config show` and
`driga config edit`. List settings are file-only and have no environment
variable.

## Path overrides

Relative values resolve against the working directory at startup.

| Variable | Default | Purpose |
|---|---|---|
| `DRIGA_CONFIG` | $XDG_CONFIG_HOME/driga/config.toml or ~/.config/driga/config.toml | Configuration file override. |
| `DRIGA_DATA_DIR` | Linux: $XDG_DATA_HOME/driga or ~/.local/share/driga; macOS: ~/Library/Application Support/driga | Database and fleet data directory override. |
| `DRIGA_SPOOL_DIR` | Linux: $XDG_STATE_HOME/driga/events or ~/.local/state/driga/events; macOS: ~/Library/Application Support/driga/events | Hook/ack spool directory override. |
