Memory and CPU by session, helpers left running after an agent ends, and old worktrees you can remove, each with its evidence and a confirm step.

</Feature>

<Section title="One service, three ways in.">

<Way command="driga" title="Terminal UI">

Keyboard first. Flow, Projects and Machines, with Chat one key away. [Flow](/guides/flow)

</Way>

<Way command="driga app" title="Desktop app">

The same views in a native window. It collects in the background, lives in the menu bar and notifies you when an agent waits. [First run](/start/first-run)

</Way>

<Way command="driga mcp" title="For scripts and agents">

Read-only MCP tools and versioned `--json` on every read command. [MCP](/guides/mcp)

</Way>

</Section>

<Section title="Local by default." layout="panel">

No account and no API key. Driga reads session files, the process table and Git on your machine. Driga is alpha: formats and behaviour can still change.

- Full transcripts are never stored.
- Nothing leaves the machine unless you pair machines, over pinned mutual TLS, or use Chat and summaries, which go through your own `claude` CLI.
- Open source, Apache 2.0. [Privacy and data](/explanation/privacy-and-data)

</Section>
