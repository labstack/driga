# Driga v1 (CLI/TUI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a single Go binary, `driga`, whose CLI and TUI show every AI coding agent session on a Mac (state, project, branch, memory), project status, orphaned helper processes, machine health, an attention inbox, and file conflicts, backed by an optional launchd collector.

**Architecture:** One collector (daemon via launchd, or one-shot "snapshot" into in-memory SQLite) gathers processes, machine stats, git state, and agent session logs through per-agent adapters, derives states/orphans/conflicts/inbox with pure functions, and writes SQLite. CLI commands and the Bubble Tea TUI are read-only readers that render the same view models as tables or versioned JSON. Hooks and acks never touch the DB: they append to a spool the collector ingests.

**Tech Stack:** Go 1.27 · `github.com/alecthomas/kong` v1.16.1 · `charm.land/bubbletea/v2` v2.1.0, `charm.land/lipgloss/v2` v2.0.6, `charm.land/bubbles/v2` v2.2.1 · `modernc.org/sqlite` v1.60.1 · `github.com/pressly/goose/v3` v3.29.0 · `github.com/shirou/gopsutil/v4` v4.26.9 · `github.com/kardianos/service` v1.3.0 · `github.com/pelletier/go-toml/v2` v2.4.3 · `log/slog` · `testing` + `github.com/google/go-cmp`.

## Global Constraints

- Module path `github.com/labstack/driga`; binary `driga`; repo root `/Users/v/Projects/labstack/driga`.
- No cgo (`CGO_ENABLED=0 go build ./...` must succeed). No fsnotify, no go-git, no network calls anywhere.
- macOS-specific code only in files named `*_darwin.go` under `internal/platform`; everything else builds on Linux (`GOOS=linux go build ./...` must succeed; Linux implementations may return `ErrUnsupported`).
- Data dir `~/Library/Application Support/driga/` (dir `0700`; `driga.db`, `driga.lock`, `viewer.heartbeat`, files `0600`). Spool dir `~/.driga/events/` (`0700`, files `0600`). Config `~/.config/driga/config.toml`. All three overridable via env `DRIGA_DATA_DIR`, `DRIGA_SPOOL_DIR`, `DRIGA_CONFIG` (tests use these; never touch the real HOME in tests).
- Config defaults (§12): `root_depth = 3`, `exclude = ["**/node_modules", "**/.tmp/**"]`, `stuck_after = "10m"`, `orphan_min_age = "10m"`, `capture_text = "titles"`, no default `roots`, `no_service_hint = false`, adapters `claude` and `codex` enabled.
- Every row carries `machine_id`. JSON payloads: `{"schema":2,"observed_at":…,"mode":"daemon"|"snapshot","freshness":{…},"coverage_gaps":[…],"data":…}`.
- Display labels exactly: `working · waiting · idle · stalled? · finished · dead · unknown`; heuristic labels prefixed `~`.
- Stored text: titles + file paths only unless `capture_text = "snippets"`; snippets ≤ 200 chars, scrubbed.
- No destructive action without an explicit `y` confirmation; reads never acknowledge inbox items.
- No user-specific values in code or defaults (§2a): no project names, terminals, or tool names outside `internal/signatures/signatures.toml`.
- Cadence (§5): idle — procs 60 s, git 5 min, machine 60 s; viewer present (heartbeat < 5 s old) — procs 5 s, git 30 s, machine 10 s. Full `git status` at least every 5 min. `lsof` cwd lookup at most every 60 s, agent pids only.
- Commits: the maintainer prefers **one commit for the whole run** rather than per-task commits (each commit needs their approval). The per-task "Commit" steps below are checkpoints: run the tests and move on; make a single commit at the end (`feat: driga v1 CLI/TUI`), or at a phase boundary only if the maintainer asks.

## Review Focus

1. **PID reuse**: a registry file whose pid now belongs to an unrelated process must read as `dead`, not alive — pinned in Task 8 (`TestRegistryPidReuse`).
2. **Huge or malformed log lines**: a single multi-MB JSONL line, invalid JSON, or unknown entry types must be skipped and counted, never crash or balloon memory — pinned in Task 6 (`TestTailOversizeLine`) and Task 8/9 (`TestParseToleratesUnknownTypes`).
3. **Path aliasing**: `/tmp` vs `/private/tmp`, symlinked repos, trailing slashes, spaces/unicode in paths must resolve to one repo/session identity — pinned in Task 7 (`TestDiscoverReposNormalizesPaths`).
4. **Collector absent or DB unavailable**: missing DB, locked DB, or no daemon must fall back to snapshot mode with a label, and `inbox ack` must report "daemon not running" — pinned in Task 16 (`TestReadFallsBackToSnapshot`) and Task 17 (`TestAckWithoutDaemon`).
5. **Process tree changing under a kill**: the orphan root exiting/being replaced between listing and kill must abort the kill — pinned in Task 17 (`TestKillAbortsOnChangedTree`).
